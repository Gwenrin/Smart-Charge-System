SMART CHARGE SYSTEM – WERSJA GLIWICE

1. Umieść wszystkie pliki w jednym folderze.

2. Zainstaluj biblioteki:
   pip install -r requirements.txt

3. Dotychczasowa wersja 8x6:
   python main.py

4. Wersja 40 dronów uruchamiana jako zwykły program:
   python main_gliwice.py

5. Wersja JupyterLab:
   jupyter lab
   Następnie otwórz plik simulation_gliwice.ipynb i wykonaj komórki po kolei.

6. Testy:
   pytest -q test_gliwice_simulation.py

Podkład OpenStreetMap wymaga połączenia z internetem podczas rysowania.
Gdy internet jest niedostępny, wykres nadal się pojawi, ale bez kafelków mapy.

Skala:
- siatka 72x56 pól,
- jedno pole 250x250 m,
- cały obszar 18x14 km,
- środek mapy ustawiony na Gliwice,
- układ metryczny EPSG:2180.
